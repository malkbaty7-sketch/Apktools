# DocShop Android

مشروع تطبيق أندرويد لعرض ومعالجة المستندات، مبني باستخدام Kotlin وJetpack Compose.

## الحالة الحالية
هذا المستودع يحتوي الآن على وصف المشروع فقط؛ لم يتم رفع ملفات المصدر الكاملة أو بناء APK بعد.

## الوظائف المخطط لها
- اختيار ملفات PDF وDOCX وXLSX وTXT وCSV والصور.
- استخراج النصوص المدعومة وتحريرها.
- تصدير النص إلى TXT وDOCX مبسط وCSV.
- OCR للصور وPDF بعد إعداد بيانات اللغة المناسبة.

## ملاحظات
- لا يدعم هذا الوصف وحده ملفات Access أو فك تشفير ملفات PDF المحمية.
- الحفاظ الكامل على تنسيق المستندات والجداول ليس مضمونًا.
- يجب بناء المشروع واختباره قبل اعتبار التطبيق جاهزًا.
