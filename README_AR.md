# DocShop — مشروع أندرويد

مشروع أولي قابل للبناء لتطبيق أندرويد باسم DocShop.

## الموجود حاليًا
- واجهة Kotlin وJetpack Compose.
- اختيار ملفات من مدير ملفات أندرويد.
- استخراج نص PDF باستخدام PDFBox، وقراءة الملفات النصية.
- تحرير النص المستخرج وحفظه كملف TXT.
- سير عمل GitHub Actions لبناء APK تجريبي عند الدفع أو يدويًا.

## حدود النسخة الحالية
هذه نسخة أولية وليست تطبيقًا مكتملًا لكل الصيغ. لا يوجد دعم فعلي حتى الآن لعرض/تحرير DOCX وXLSX الأصليين، أو Access، أو OCR عربي مدمج، أو فك تشفير PDF المحمي. لا يُضمن الحفاظ على تنسيق PDF والجداول والتشكيلات عند استخراج النص. يجب اختبار البناء على GitHub Actions وتجربة التطبيق على جهاز أندرويد قبل اعتباره جاهزًا.

## البناء
من تبويب Actions في GitHub شغّل workflow باسم **Build DocShop Android APK**، ثم نزّل artifact باسم **DocShop-debug-apk** إذا نجح البناء.
